# math-lecture-standard

把「数学怎么讲才算讲透」这件事，从口头要求固化成一条可执行的流水线。

> 一句话：**每次讲数学、每建或改一张数学页，先读这份再动手。**
> ★ **R22（v0.2.0 新增）**：凡数学讲解线任务，第一个动作先加载本 skill，不许凭记忆或上一轮上下文直接开讲。

---

## 它解决什么

跟 AI 学数学最常见的失败方式，是它给你一份**看起来很对但读不进去**的推导：

- 一上来就甩公式，不告诉你这题在考什么
- 证明绕一圈，同一个条件用了两次却不点破
- 该画图的地方只写文字，几何直观全靠你自己想
- 公式只给结果，不讲「为什么长这样」
- 讲完没有自测，你不知道自己到底会不会
- **只在对话里讲完，没有落成一份能反复看的页面**（v0.2.0 补）
- **手机上公式被压成小字、图被裁掉右半**（v0.2.0 补）

这份标准就是针对这些的反面清单。它不教你数学，它约束的是**讲解的形状**。

## 铁律 22 条（R1–R22）

完整条文见 [`SKILL.md`](SKILL.md) 第一节，这里只列骨架：

| 编号 | 规则 |
|---|---|
| R1 | **四件套**：讲定理/工具必给「直觉 + 小微例 + 何时用 + 连接」，讲完附自测清单 |
| R2 | **先思路后公式**：开头一句话点明「这题在考什么、为什么这么做」 |
| R3 | **证明步递进不绕圈**：每步必须推出新信息；同一条件用两次要点破「一因两果」 |
| R4 | **主动排雷车轱辘话**：跨题共用的知识点显式标注「这是某题的逆 / 倒装」 |
| R5 | **反例构造讲清怎么挑**：不能凭空冒出一个数列 |
| R6 | **数形结合是硬性**：凡能画图的**必须配 SVG**，图文并茂 |
| R7 | **公式要形象推导**：核心公式必须讲「为什么长这样」，不能只列结果 |
| R8 | **讲细 + 公式要全**：基本表、两类换元、分部、部分分式，不省略中间步 |
| R9 | **每步打标签**：【换元】【套公式】【经典变形】【分部】让阅读者看清这步在干啥 |
| R10 | **前置科普三问**：与已会知识的区别 / 为什么这么切 / 去术语看本质 |
| R11 | **原题不能丢**：加讲解或前置科普时，题干、步骤、答案完整保留 |
| R12 | **红笔答案即正确**：用户订正过的答案视为对，只能质疑过程瑕疵 |
| R13 | **变更实时同步**：新要求当场改产品 → 同步镜像 → 登记交接总线 |
| R14–R15 | 答案区要「散」不要「挤」；练习型先给答案后给过程，说明块盒子化 |
| R16 | **计算题必须给「纸上动作」**：写清手在纸上怎么动，不给结论式步骤 |
| R17 | **同一份卷子只出一页**：分批贴图视为同一张卷子，按题号重排，旧页保留加横幅 |
| R18 | **一图一审**：SVG 逐张渲 PNG 目视，查压线 / 重叠 / 越界 / 图形本身画错 |
| R19 | **讲新符号先「拆符号」再「讲规则」**：∫、dx 这类零件逐个讲清身份与作用域 |
| R20 | **题目优先 + 工具可跳转 + 手机适配**：工具卡放题目之后，徽章点击跳转，默认单列 |
| R21 | **讲题一律落 HTML 页，且每题卡内必须配图**：内嵌示意图不能替代页面 |
| R22 | **skill 常驻调用**：数学线任务第一个动作加载本 skill，续接后的新一轮仍重新加载 |

另有**坑表 21 条（P1–P21）**，全是真踩过的：双 BOM 毁 DOCTYPE、根号被全局 CSS 打塌、非 raw 字符串里 `\frac` 的 `\f` 变换页符、LaTeX 双反斜杠让公式「不报错但显示错」、题卡图字太小被裁等。见 `SKILL.md` 第四节。

## 出页流水线（四步）

1. **定载体** —— 先决定是逐题详解 / 聚焦讲评 / 定理速通 / 公式速查；一律自包含 KaTeX HTML（CSS、JS、字体全内联，不走 CDN）
2. **搭生成器** —— 从 [`references/page-skeleton.md`](references/page-skeleton.md) 的骨架起手，**不手写 HTML**；题目为主的讲评页复用共享的手机优先骨架
3. **六关校验** —— 跑 [`scripts/validate_math_page.py`](scripts/validate_math_page.py)，一关不过不许交付
4. **交付** —— 打开页面，同时**把核心结论贴进回复正文**（写了文件不等于交付）

### 六关校验

```bash
python scripts/validate_math_page.py 页面.html              # 静态关
python scripts/validate_math_page.py 页面.html --headless   # 追加无头渲染关
python scripts/validate_math_page.py 页面.html --expect 226 # 断言公式节点数
```

| 关 | 判据 |
|---|---|
| ① BOM | 前置 BOM 恰好 1 个（双 BOM 会让脚本不跑、0 渲染） |
| ② 标签 | HTMLParser 残留栈 = 0，stray-end = 0 |
| ③ 公式字符 | `$…$` 内不得有裸 `<` / `>`（写 `\lt` / `\gt`）；无替换符 |
| ④ 目录 | toc 链接数与条目数一致，锚点 id 全部存在 |
| ⑤ 渲染 | 无头浏览器 dump-dom 后 `class="katex"` > 0 且 `katex-error` = 0 |
| ⑥ 标题 | `<title>` 必须等于本页 `<h1>`，不得残留外壳模板标题 |

退出码 `0` 全过 / `1` 有问题。任何一关 FAIL 都不许交付。

> 注意：**六关全 PASS 也不等于图没问题**（R18）。文字压在曲线上、两个标签撞车、文字冲出右边界，自动校验查不出来，必须逐张渲成 PNG 目视。

## 安装

把整个目录放进你的 skill 目录即可：

```bash
# WorkBuddy
cp -r math-lecture-standard ~/.workbuddy/skills/

# 其他支持 SKILL.md 的 Agent
cp -r math-lecture-standard <你的 skills 目录>/
```

无外部依赖。`validate_math_page.py` 只用标准库；`--headless` 那关需要本机有 Edge 或 Chrome。

## 适用 / 不适用

**适用**：高数、线代、概率统计、竞赛数学的逐题讲解与页面产出；公式库建设；练习批改对照；手机端阅读的讲评页。

**不适用**：它不是数学教材，不含题库，也不做任何自动解题。它只约束「讲成什么样」。

## 关于隐私

这份标准诞生于一个真实的学习场景，公开前已系统性脱敏：
学号、姓名、学校、班级、本地绝对路径、考试名称、内部协作编号一律移除或泛化；
课程与教材内部称呼改为通用表述；不搬题库原文，只保留方法论与少量示例。

`SKILL.md` 第七节保留了一份完整的开源检查清单，供同类 skill 复用 —— 包括那条「**规则自己也可能带着隐私**」的经验：写着「要删学号」的文档，曾把真实学号当例子写进括号里。所以扫描必须覆盖 `.md`、注释和说明文字，而不只是数据文件。
